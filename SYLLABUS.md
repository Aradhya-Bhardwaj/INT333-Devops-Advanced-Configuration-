# INT333: DevOps Advance Configuration Management

Unit-wise syllabus (session 2026-27), with where each topic appears in this repository.

L:2 T:0 P:2, 3 credits

## Course outcomes

| CO | Students should be able to | Unit |
| --- | --- | --- |
| CO1 | Understand the basics of Puppet | I |
| CO2 | Demonstrate configuration management skills using Puppet | II |
| CO3 | Install and configure Nagios for continuous monitoring | III |
| CO4 | Understand and implement infrastructure automation using Terraform | IV |
| CO5 | Describe the fundamentals of Ansible and its installation | V |
| CO6 | Construct Ansible playbooks to automate system administration tasks | VI |
